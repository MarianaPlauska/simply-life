# @simply-life/ui-tokens — AXEL Premium

Source of truth for the lifestyle redesign (amber AXEL, elevated cards, Manrope UI).

## Usage

```ts
import { colorsFor, TYPE_SCALE, RADIUS, SPACE, COMPONENT_SPEC } from '@simply-life/ui-tokens'

const c = colorsFor('light')
```

## Acceptance

- Body ≥ 13px on mobile
- Card radius ≥ 16px (target 20)
- Touch targets ≥ 44px
- Amber reserved for brand/CTA/voice — not generic chrome
- Same shell width across tab switches
